# Automated BL Setup

## Overview

This project aims to automate the existing PL setup to enable sample testing with minimal manual intervention.

The objective is to automate the operations currently performed manually during the sample testing process, making the overall procedure more efficient and repeatable.

## Current Implementation

The initial implementation focuses on the homing functionality using an IR gap sensor. This provides a reference position for the automated setup.

The Arduino code for this functionality is available in `automated_pl.ino`.

## Development Status

The initial homing implementation is available, but it has not yet been tested on the actual hardware (IR Gap sensor has been ordered and delivered).
